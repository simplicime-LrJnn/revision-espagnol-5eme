2. Les Chiffres Romains

Ce sont des lettres ayant une valeur numérique : I = 1, V = 5, X = 10.

Règles de répétition :

On peut répéter 3 fois maximum les chiffres I et X (ex: III = 3, XXX = 30). V ne se répète qu'une seule fois.

Règle de Soustraction & Addition :
  • Si I est devant V ou X ➔ Soustraction (IV = 4, IX = 9).
  • Si I est derrière V ou X ➔ Addition (VI = 6, XI = 11).

3. Présenter un document (DANSS)

Pour identifier et présenter un document historique, il faut toujours fournir 5 informations (D.A.N.S.S) :

D
Date : C'est la date ou le siècle où le document a été fait.
A
Auteur : C'est la personne qui a réalisé le document.
N
Nature : Le type de document (texte, photo, carte, graphique, sculpture...).
S
Source : D'où vient le document (livre, musée, journal, site internet...).
S
Sujet : De quoi parle l'auteur dans ce document.
📌 Modèle de rédaction idéal :

« Le document (N) est un [Nature] écrit par [Auteur] au [Date]. Il est extrait de [Source]. L'auteur parle de [Sujet]. »
